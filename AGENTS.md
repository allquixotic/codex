# Project instructions

Never perform GUI testing for this project on Sean's Mac. Never launch the
project's GUI, pop up test windows, or run GUI tests on this Mac. This prohibition
persists across tasks and sessions. Only the user's explicit instruction
"test the GUI on this Mac" authorizes an exception. Do not infer an exception
from requests to fix, build, verify, commit, push, or release the project.

Use Windows hosts for GUI testing. Non-interactive source inspection, formatting,
linting, compilation and Windows cross-builds on the Mac remain permitted.
